O Aloha é uma plataforma de jogos sociais e party games para jogar sozinho ou presencialmente com amigos.

As páginas legais em HTML acompanham `docs/legal/` do repositório `PlayAloha/aloha-app`; em caso de divergência entre idiomas, prevalece o texto em português.
